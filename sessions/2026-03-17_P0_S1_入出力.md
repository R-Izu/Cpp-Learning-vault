# 2026-03-17 — Phase 0 Session 1: 入出力と型

## 出題した問題と回答コード

### Q1: 基本的な四則演算
整数 `A` と `B` が空白区切りで与えられます。`A * B` （長方形の面積） と `2 * (A + B)` （長方形の周の長さ） を空白区切りで出力するプログラムを書いてください。

**提出コード:**
```cpp
# include<iostream>
using namespace std;

int main(){
    int A, B;
    cin >> A >> B;

    cout << A*B << " " << 2*(A+B) << endl;

    return 0;
}
```

**レビュー結果:**
- 良い点: `cin` と `cout` を使って正しく入出力ができています。`endl` による改行も適切です。
- 問題点: とくにありません。完璧な実装です！(強いて言えば `# include` と山括弧の間のスペースは不要なので、`#include <iostream>` と書くのが一般的です)

### Q2: 浮動小数点数の出力
整数 `a` と `b` が空白区切りで与えられます。
`a / b` (整数部分)、`a % b` (余り)、`a / b` (実数、浮動小数点数) の3つを空白区切りで出力するプログラムを書いてください。

**提出コード:**
```cpp
# include<iostream>
using namespace std;

int main(){
    int a, b;
    cin >> a >> b;

    int integer = a/b;
    int rem = a%b;
    float real = (float)a/b;

    cout << integer << " " << rem << " " << real << endl;

    return 0;   
}
```

**レビュー結果:**
- 良い点: `/` 演算子と `%` 演算子の使い分けができており、整数と余りの計算が正しく行えています。
- 問題点: 
  1. 浮動小数点数の型として `float` を使っています。C++で精度が求められる計算をする場合は、より有効数字が多い（15桁程度）`double` 型を用いるのが一般的です。`float` では誤差が発生しやすくなります。
  2. キャストとして C言語スタイルの `(float)a` を使用していますが、C++ではより意図が明確で安全な `static_cast<double>(a)` などを推奨します。

### Q3: 文字列の入出力
文字列 `S` が入力されます。`Hello, S!` と出力するプログラムを書いてください。

**提出コード:**
```cpp
# include<iostream>
using namespace std;

int main(){
    string S;

    cin >> S;
    cout << "Hello, " << S << "!" << endl;

    return 0;   
}
```

**レビュー結果:**
- 良い点: `std::string` 型を宣言し、文字列の連結的な出力を簡潔に記述できています。
- 問題点: プログラムとして正しく動作しますが、文字列を使う場合は `#include <string>` を明示的に追加したほうが安全です。（コンパイラ環境によってはエラーになるため）
